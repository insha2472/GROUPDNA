# GROUPDNA

A Python-based WhatsApp group chat analyzer built for The Unlox Academy minor project.

### Features
- Chat parsing
- Group activity analysis
- Activity heatmap using NumPy
- Top words
- Response speed & silent days
- Personality archetypes
- Final report

### Technologies
Python • NumPy • File Handling • datetime

### Dataset
`hostel_bois.txt` — synthetic WhatsApp group chat dataset.
